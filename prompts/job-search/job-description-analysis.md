# Job Description Analyzer

> Break down a target job description to distinguish required vs. preferred skills, extract hidden expectations, and identify potential red flags.

## What This Prompt Does

This prompt performs a deep audit of a job posting. It categorizes requirements into Must-Have, Preferred, and Nice-to-Have skills, extracts key ATS keywords, identifies technical and soft skill needs, and flags potential workplace concerns or ambiguous expectations.

## Best For

- Understanding what a hiring manager truly values before applying.
- Deciding whether a role is worth investing time into for a tailored application.
- Preparing tailored resume bullet points and interview responses.

## Information You Need

- Target Job Title & Company Name
- Full Job Description Text

## Copy & Paste Prompt

```text
Act as a senior technical recruiter and talent analyst.

TASK:
Analyze the provided job description and break down its core requirements, hidden expectations, skill priorities, and potential red flags.

INPUT DATA:
- Target Job Title: [TARGET_JOB_TITLE]
- Company Name: [COMPANY_NAME]
- Job Posting Text: [JOB_DESCRIPTION]

ANALYSIS BREAKDOWN:
1. Role Snapshot: Seniority level, primary purpose of the role, and core team context.
2. Tiered Skill Requirements:
   - REQUIRED (Must-Have skills/experience)
   - PREFERRED (Strong advantage skills)
   - NICE-TO-HAVE (Bonus points)
3. Essential ATS Keywords & Technical Tools List.
4. Soft Skills & Cultural Values Required.
5. Potential Ambiguities & Red Flags (e.g., unrealistic workload indicators, vague compensation language, conflicting responsibilities).
6. Recommended Interview Focus Topics.

CONSTRAINTS:
- Do not treat all listed skills as equally important; distinguish core priorities clearly.
- Provide objective, analytical insights without fluff.

OUTPUT FORMAT:
Markdown report structured with clear headings and bulleted summary tables.
```

## How to Use

1. Copy the prompt block above.
2. Insert the job posting text into `[JOB_DESCRIPTION]`.
3. Run the prompt in your AI assistant.
4. Use the analysis table to focus your resume tailoring and interview prep.

## Expected Output

A detailed diagnostic report categorizing requirements, extracting keywords, and identifying potential concerns.

## Tips

- Pay close attention to "Required" vs "Preferred" tiers—many candidates drop out unnecessarily over missing preferred skills.
- Use the extracted technical keywords directly in your resume skills section.

## Notes

- Job postings are often wish lists; meeting 70-80% of core requirements makes you a viable candidate.
