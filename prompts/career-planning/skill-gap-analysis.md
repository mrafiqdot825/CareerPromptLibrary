# Skill Gap Analysis & Learning Matrix

> Audit your current technical and soft skills against target role benchmarks to pinpoint critical gaps and build a prioritized learning plan.

## What This Prompt Does

This prompt conducts an objective skill gap analysis by comparing your self-reported qualifications against industry benchmarks for a target position. It prioritizes missing skills by urgency and impact, suggesting effective learning resources and project ideas.

## Best For

- Preparing for a promotion or step-up role.
- Prioritizing which online courses, certifications, or books to invest time in next.
- Staying competitive against evolving market requirements.

## Information You Need

- Current Skillset & Proficiency Levels
- Target Role Title & Target Seniority Level
- Sample Job Description / Industry Standard

## Copy & Paste Prompt

```text
Act as a learning & development director and senior technical competency auditor.

TASK:
Perform a skill gap analysis comparing my current competencies against standard industry requirements for [TARGET_JOB_TITLE], and generate a prioritized learning matrix.

INPUT DATA:
- Target Job Title & Level: [TARGET_JOB_TITLE]
- Current Technical & Soft Skills: [SKILLS]
- Experience Level: [YEARS_OF_EXPERIENCE]
- Industry Sector: [TARGET_INDUSTRY]

AUDIT & LEARNING MATRIX:
1. Benchmark Competency Profile: Standard hard and soft skills required for top performance in [TARGET_JOB_TITLE].
2. Gap Identification:
   - Priority 1 (Critical Gaps - Must acquire immediately)
   - Priority 2 (Secondary Gaps - Advantageous for growth)
   - Priority 3 (Refinement Gaps - Polish existing capabilities)
3. Recommended Action Plan: Specific learning approaches (e.g., certifications, hands-on projects, open-source contribution) per critical gap.
4. Estimated Time to Competency.

CONSTRAINTS:
- Keep skill evaluations grounded in realistic industry demands.
- Avoid recommending low-value fluff courses; focus on practical application.

OUTPUT FORMAT:
Markdown report featuring a formatted Skill Gap Matrix table followed by an actionable learning plan.
```

## How to Use

1. Copy the prompt block.
2. Fill in `[TARGET_JOB_TITLE]`, `[SKILLS]`, `[YEARS_OF_EXPERIENCE]`, and `[TARGET_INDUSTRY]`.
3. Run the prompt in your AI assistant.
4. Use the Priority 1 skill gaps to set your quarterly learning goals.

## Expected Output

A prioritized skill matrix table ranking missing competencies alongside practical learning recommendations and time estimates.

## Tips

- Focus on mastering one Priority 1 skill at a time rather than spreading effort across multiple tools simultaneously.
- Apply new skills immediately through small personal projects to solidify learning.

## Notes

- Regular skill gap audits keep your professional profile resilient against industry shifts.
