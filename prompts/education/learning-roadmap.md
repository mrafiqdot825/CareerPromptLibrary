# Self-Taught Learning Roadmap Curriculum

> Construct a self-guided curriculum to master a new skill or field from scratch using free or open-access learning resources.

## What This Prompt Does

This prompt designs a complete self-study learning path for mastering a new domain (e.g., Full-Stack Web Development, Data Analytics, UX Design, Cloud Engineering). It breaks down prerequisite concepts, core modules, portfolio projects, and resource recommendations.

## Best For

- Self-taught developers, designers, or analysts learning independently.
- Structuring bootcamps or self-directed study without paying expensive tuition.
- Building hands-on portfolio projects alongside theoretical learning.

## Information You Need

- Target Skill / Subject to Learn
- Current Prerequisite Knowledge Level
- Learning Style Preference (e.g., Project-based, Video lectures, Reading documentation)

## Copy & Paste Prompt

```text
Act as a curriculum designer and lead technical instructor.

TASK:
Design a structured, project-based self-study learning curriculum to take me from my current knowledge level to proficiency in [TARGET_SKILL].

INPUT DATA:
- Target Skill / Field: [TARGET_SKILL]
- Current Knowledge Baseline: [CURRENT_KNOWLEDGE_LEVEL]
- Time Commitment: [WEEKLY_HOURS_AVAILABLE]
- Preferred Learning Style: [LEARNING_STYLE]

CURRICULUM MODULES:
1. Module 1: Foundations & Prerequisites (Core principles, setup, terminology).
2. Module 2: Core Concepts & Tooling (Hands-on frameworks and syntax).
3. Module 3: Intermediate Application (Integrating components, real-world patterns).
4. Module 4: Advanced Mastery & Best Practices (Performance, security, architecture).
5. Portfolio Milestone Projects: 3 specific, real-world projects to build to prove mastery.

CONSTRAINTS:
- Prioritize high-quality, open-access, or widely recommended learning resources.
- Ensure every module includes a practical hands-on building component.

OUTPUT FORMAT:
Structured Markdown curriculum featuring module objectives, recommended topics, and project specifications.
```

## How to Use

1. Copy the prompt block above.
2. Fill in `[TARGET_SKILL]`, `[CURRENT_KNOWLEDGE_LEVEL]`, `[WEEKLY_HOURS_AVAILABLE]`, and `[LEARNING_STYLE]`.
3. Generate the curriculum in your AI model.
4. Follow the modules sequentially and build each portfolio milestone project.

## Expected Output

A 4-module self-study curriculum complete with learning outcomes, topic breakdowns, and portfolio project specifications.

## Tips

- Do not move to advanced modules until you have built the hands-on project for the foundation module.
- Store all project code on GitHub to build your proof-of-work early.

## Notes

- Portfolio projects demonstrate mastery far more effectively than certificates of completion alone.
