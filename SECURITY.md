# Security Policy

## Overview

**CareerPromptLibrary** is a collection of open-source text prompts, documentation, and markdown templates for AI assistance. It does not execute binary code or host server infrastructure. However, security, user privacy, and data protection remain important priorities.

## Privacy & Safe Usage Guidelines

When using AI prompts from this repository, please observe the following privacy best practices:

1. **Protect Sensitive Information**: Do not paste highly confidential personal data (such as Social Security Numbers, financial account details, passwords, or proprietary employer code/trade secrets) into commercial AI platforms.
2. **Review AI Outputs**: Always review generated resumes, cover letters, and communications to ensure accuracy and prevent unintentional disclosure of private information.
3. **Verify Third-Party Services**: Ensure you understand the data retention policies of the AI model provider (ChatGPT, Claude, Gemini, etc.) you choose to use.

## Reporting Security or Privacy Issues

If you identify broken links, malicious content submissions, or privacy concerns within this repository:

* Please open a issue using our **[Bug Report Template](.github/ISSUE_TEMPLATE/bug-report.md)** or contact project maintainers directly via repository management.
* Maintainers will review and address reported concerns promptly.

Thank you for helping keep the CareerPromptLibrary community safe and respectful.
