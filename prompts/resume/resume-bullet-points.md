# Resume Bullet Point Optimizer

> Transform weak or passive job duty bullets into accomplishment-focused impact statements using proven resume formulas.

## What This Prompt Does

This prompt restructures job responsibilities using the Google XYZ Formula: *"Accomplished [X] as measured by [Y], by doing [Z]"* or the Action + Context + Result format. It strengthens action verbs and highlights measurable outcomes based on user data.

## Best For

- Upgrading "Responsible for..." duty lists into accomplishment bullets.
- Demonstrating clear business impact and problem-solving ability.
- Making work history bullet points readable, punchy, and compelling.

## Information You Need

- Current Bullet Points or Duty Notes
- Role Title & Company Sector
- Raw Metrics or Qualitative Outcomes (e.g., saved time, increased efficiency, led a team of 4)

## Copy & Paste Prompt

```text
Act as an expert resume writer specializing in achievement-based resume bullet points.

TASK:
Rewrite my job duty notes into powerful, impact-driven resume bullet points.

INPUT DATA:
- Role Title: [TARGET_JOB_TITLE]
- Industry: [TARGET_INDUSTRY]
- Raw Job Duties & Notes: [WORK_EXPERIENCE]
- Available Metrics / Outcomes: [ACHIEVEMENTS]

REWRITING FORMULA:
Use the structure: [Strong Action Verb] + [Specific Task & Context] + [Measurable Impact or Value Delivered].

CONSTRAINTS:
1. Do NOT invent fake percentages, revenue numbers, or metrics.
2. If no metric is supplied in the input, focus on qualitative business impact (e.g., streamlined workflow, improved accuracy, reduced processing delays).
3. Start every bullet point with a unique, active verb.
4. Avoid passive phrasing ("Worked on", "Responsible for", "Assisted with").

OUTPUT FORMAT:
For each duty input provided, present:
- Original Note
- Optimized Option A (Metric/Data Focused, if data available)
- Optimized Option B (Process & Outcome Focused)
```

## How to Use

1. Copy the prompt block above.
2. Insert your raw job duty bullet points into `[WORK_EXPERIENCE]`.
3. Add any real results or metrics into `[ACHIEVEMENTS]`.
4. Run the prompt and choose the strongest revised bullet points.

## Expected Output

Side-by-side comparison showing your original notes alongside 2 polished, high-impact options per bullet point.

## Tips

- If you don't have precise metrics, estimate conservatively or state scale (e.g., "managed a budget across 5 departments").
- Keep bullet points between 1 and 2 lines long when formatted on a document.

## Notes

- Bullet points starting with strong verbs catch an interviewer's eye during 6-second initial scans.
