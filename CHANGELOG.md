# Changelog

All notable changes to **CareerPromptLibrary** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-09

### Added
- Initial release of **CareerPromptLibrary**.
- **Resume Category**: 7 comprehensive prompts (`ats-resume.md`, `resume-from-scratch.md`, `resume-improvement.md`, `resume-summary.md`, `resume-bullet-points.md`, `resume-keywords.md`, `resume-tailoring.md`).
- **Cover Letter Category**: 3 tailored prompts (`cover-letter.md`, `job-specific-cover-letter.md`, `cold-application-cover-letter.md`).
- **Job Search Category**: 5 strategic prompts (`job-search-strategy.md`, `job-description-analysis.md`, `job-match-analysis.md`, `application-strategy.md`, `career-opportunity-analysis.md`).
- **LinkedIn Category**: 5 profile & branding prompts (`linkedin-profile.md`, `linkedin-headline.md`, `linkedin-about.md`, `linkedin-experience.md`, `linkedin-content.md`).
- **Interviews Category**: 6 preparation & practice prompts (`interview-preparation.md`, `behavioral-interview.md`, `technical-interview.md`, `mock-interview.md`, `interview-questions.md`, `interview-feedback.md`).
- **Career Planning Category**: 5 career development prompts (`career-roadmap.md`, `career-change.md`, `skill-gap-analysis.md`, `career-goals.md`, `five-year-plan.md`).
- **Education Category**: 5 learning & academic prompts (`study-plan.md`, `learning-roadmap.md`, `course-selection.md`, `scholarship-application.md`, `internship-application.md`).
- **Freelancing Category**: 4 client & proposal prompts (`freelancer-profile.md`, `freelance-proposal.md`, `client-pitch.md`, `freelance-niche.md`).
- **Workplace Category**: 5 communication & review prompts (`professional-email.md`, `meeting-preparation.md`, `performance-review.md`, `promotion-request.md`, `professional-communication.md`).
- **Templates**: Standard prompt template, resume input template, and job description template.
- **Documentation**: Comprehensive getting started guide, prompt engineering standards, and FAQ.
- **Community Standards**: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, GitHub issue templates, and pull request template.
