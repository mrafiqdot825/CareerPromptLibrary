# Job Description Input Template

Use this template to clean and organize raw job descriptions from posting boards (LinkedIn, Indeed, company career pages) before pasting them into career prompts.

---

```text
==================================================
JOB POSTING METADATA
==================================================
Job Title: [TARGET_JOB_TITLE]
Company Name: [COMPANY_NAME]
Location / Remote Status: [JOB_LOCATION]
Employment Type (Full-time, Contract, etc.): [EMPLOYMENT_TYPE]

==================================================
ROLE OVERVIEW / SUMMARY
==================================================
[PASTE_JOB_SUMMARY_HERE]

==================================================
KEY RESPONSIBILITIES
==================================================
- [RESPONSIBILITY_1]
- [RESPONSIBILITY_2]
- [RESPONSIBILITY_3]
- [RESPONSIBILITY_4]

==================================================
REQUIRED QUALIFICATIONS & SKILLS
==================================================
- [REQUIRED_QUALIFICATION_1]
- [REQUIRED_QUALIFICATION_2]
- [REQUIRED_SKILL_1]
- [REQUIRED_SKILL_2]

==================================================
PREFERRED / NICE-TO-HAVE QUALIFICATIONS
==================================================
- [PREFERRED_QUALIFICATION_1]
- [PREFERRED_QUALIFICATION_2]

==================================================
TECHNOLOGIES & TOOLS MENTIONED
==================================================
- [TOOL_OR_TECH_1]
- [TOOL_OR_TECH_2]
==================================================
```
