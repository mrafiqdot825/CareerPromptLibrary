# Student & Early-Career Internship Application Generator

> Create student resumes and cover letters for internship and co-op applications, highlighting coursework, academic projects, and leadership.

## What This Prompt Does

This prompt helps students and recent graduates build compelling application materials when they have limited formal work experience. It emphasizes relevant coursework, academic team projects, extracurricular leadership, student clubs, and technical skills.

## Best For

- University and college students applying for summer internships or co-ops.
- Recent graduates building their first professional resume.
- Positioning academic project work as real-world experience.

## Information You Need

- University Name, Degree, & Expected Graduation Date
- Relevant Coursework Completed
- Academic Projects / Lab Work
- Extracurriculars, Student Clubs, or Volunteer Work
- Target Internship Title & Company Name

## Copy & Paste Prompt

```text
Act as a university career center director and campus recruiter.

TASK:
Build a tailored early-career internship application package (Resume bullet points & Cover Letter) based on my academic background and coursework.

INPUT DATA:
- Candidate Name: [YOUR_NAME]
- University & Major: [EDUCATION]
- Expected Graduation: [GRADUATION_YEAR]
- Target Internship Title: [TARGET_JOB_TITLE]
- Target Company: [COMPANY_NAME]
- Key Coursework: [RELEVANT_COURSEWORK]
- Academic Projects / Labs: [PROJECTS]
- Clubs / Extracurriculars: [EXTRACURRICULARS]
- Technical / Soft Skills: [SKILLS]

GENERATION OUTPUTS:
1. Student Resume Format: Emphasizing Academic Projects with action-verb bullet points formatted like work experience entries.
2. Tailored Internship Cover Letter: Short, enthusiastic letter (200-250 words) connecting coursework and passion to the company's internship program.

CONSTRAINTS:
- Do NOT fabricate work experience or project outcomes.
- Frame academic projects with clear problem-statement and results.

OUTPUT FORMAT:
Markdown document formatted with separate Resume and Cover Letter sections.
```

## How to Use

1. Copy the prompt block.
2. Fill in your academic details, coursework, projects, and target internship info.
3. Run the prompt in your AI assistant.
4. Copy the formatted sections into your student resume and cover letter templates.

## Expected Output

An early-career application packet containing structured academic project bullet points and an internship cover letter.

## Tips

- Treat major course projects like job entries—list the project title, tools used, and key outcomes.
- Include linkable GitHub or portfolio URLs to show live code or design samples.

## Notes

- Campus recruiters prioritize enthusiasm, quick learning capacity, and project initiative over formal corporate tenure.
