# Workplace Boundary & Assertive Communication Script

> Draft assertive, professional communication scripts to set workload boundaries, manage scope creep, and handle difficult workplace conversations.

## What This Prompt Does

This prompt helps you communicate professionally when setting boundaries at work (e.g., declining additional tasks when at capacity, addressing scope creep, resolving peer friction). It provides 3 verbal communication scripts tailored for managers, clients, or peers.

## Best For

- Setting healthy work-life boundaries without appearing uncooperative.
- Managing project scope creep professionally.
- De-escalating tense conversations or handling workplace pushback smoothly.

## Information You Need

- Scenario / Conflict Situation
- Stakeholder Involved (Manager, Peer, Client)
- Boundary / Outcome to Maintain

## Copy & Paste Prompt

```text
Act as an executive communication coach and workplace mediation specialist.

TASK:
Draft 3 professional, assertive communication scripts to handle a challenging workplace boundary or conversation scenario.

INPUT DATA:
- Communication Scenario: [WORKPLACE_SCENARIO]
- Stakeholder Role: [RECIPIENT_ROLE]
- Boundary / Outcome Needed: [DESIRED_OUTCOME]
- Constraints / Context: [FACTS_TO_CONVEY]

SCRIPT VARIATIONS:
1. Direct & Collaborative Script (Best for 1-on-1 calls with your manager).
2. Written Email / Slack Response Script (Best for documented communication).
3. Brief De-escalation Script (Best for real-time meeting pushback).

COMMUNICATION PRINCIPLES:
- Acknowledge stakeholder priorities while clearly communicating capacity/boundary realities.
- Offer constructive trade-offs (e.g., "If we prioritize Project A, which of these lower-priority tasks should we pause?").
- Use calm, firm, neutral language without defensive apologetic phrasing.

CONSTRAINTS:
- Do NOT use overly aggressive or overly submissive language.

OUTPUT FORMAT:
Markdown document presenting 3 distinct scripts with brief delivery notes for each.
```

## How to Use

1. Copy the prompt block.
2. Fill in the scenario, stakeholder role, boundary needed, and constraints.
3. Generate the communication scripts in your AI assistant.
4. Practice delivering the script before your meeting or conversation.

## Expected Output

Three situational communication scripts (Verbal 1-on-1, Written document, and In-meeting response) accompanied by delivery notes.

## Tips

- Offer trade-offs instead of saying a flat "no" (e.g., "I can take on Task X, but it means Task Y will be delayed by two days—which takes priority?").
- Avoid starting sentences with unnecessary apologies (like "Sorry to bother you...").

## Notes

- Assertive, solution-oriented boundary setting earns long-term respect in corporate environments.
