# Resume Keyword Optimizer

> Extract essential hard skills, soft skills, and industry terminology from a job posting and seamlessly weave them into your resume.

## What This Prompt Does

This prompt performs a side-by-side keyword analysis between a target job description and your current resume. It identifies critical missing terms and suggests precise placement locations within your skills section, summary, or work experience.

## Best For

- Maximizing ATS keyword match scores for online applications.
- Identifying missing industry terminology or tool names you possess but forgot to list.
- Ensuring keyword integration sounds natural to human hiring managers.

## Information You Need

- Target Job Description
- Your Current Resume Text

## Copy & Paste Prompt

```text
Act as an ATS Optimization Expert and Talent Acquisition Consultant.

TASK:
Analyze the provided job description against my resume text, extract high-priority keywords, and demonstrate how to integrate missing keywords naturally.

INPUT DATA:
- Target Job Description: [JOB_DESCRIPTION]
- Current Resume Content: [WORK_EXPERIENCE]

ANALYSIS PROCESS:
1. Extract Top Keywords from Job Description (categorized as Hard Skills, Soft Skills, Tools & Methodologies, and Industry Terminology).
2. Cross-reference extracted keywords with my resume.
3. Identify Missing Keywords that are critical to the role.
4. Recommend Natural Integrations for missing keywords into my resume text.

CONSTRAINTS:
- Do NOT suggest adding skills or keywords that I do not actually possess.
- Avoid keyword stuffing (repeating keywords unnaturally or listing skills without context).
- Focus on context-rich integration into experience bullet points where applicable.

OUTPUT FORMAT:
1. Categorized Keyword Extraction Table (Found vs Missing)
2. Strategic Keyword Placement Recommendations (Where and how to add them)
3. Revised Resume Sections showing seamless integration
```

## How to Use

1. Copy the prompt block.
2. Paste the target job description into `[JOB_DESCRIPTION]`.
3. Paste your current resume into `[WORK_EXPERIENCE]`.
4. Run the prompt and implement recommended keyword placements.

## Expected Output

A categorized breakdown of matching and missing keywords, accompanied by specific text edit suggestions for your resume.

## Tips

- Only add keywords for technologies or processes you are prepared to discuss in an interview.
- Match exact phrasing where possible (e.g., "Project Management" vs "Managing Projects").

## Notes

- Modern ATS systems check keyword context and frequency, so natural placement within achievement bullets is key.
